# Nohook MVP

베트남 관광지의 위험 도로를 위성 지도 위에 색으로 표시하는 `Nohook` MVP입니다.

현재 버전은 `Google Maps JavaScript API` 대신 `MapLibre + 공개 raster 위성 타일`을 사용합니다. 그래서 별도 Google API 활성화 없이도 위성 지도가 먼저 뜨고, 타일 로딩 실패 시 데모 지도로 자동 전환됩니다.

## 포함 기능

- 위성 지도 기반 위험 도로 오버레이
- 호치민 1군 / 하노이 올드쿼터 핵심 구간 표시
- 도로 상세 패널
- 익명 신고 폼
- 운영 검수 프리뷰 `/admin`

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

## 환경변수

현재는 필수 지도 API 키가 없습니다.

`.env.local` 없이도 실행할 수 있습니다.

## 배포 메모

- 기본 지도는 공개 위성 타일을 사용합니다.
- 외부 타일이 실패하면 앱은 자동으로 데모 지도로 내려갑니다.
- 위험도 데이터와 신고 API는 목업 기반입니다.
